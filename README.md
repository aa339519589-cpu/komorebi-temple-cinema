# KOMOREBI v59

完整可运行的寺院场景源码。需要 Node.js 24.2 或更新：执行 `node verify.mjs` 后运行 `node serve.mjs`，按终端地址打开浏览器。参考10条件场景使用 `/?scene=reference10-porch`，其他参考共用默认场景。需要可用 WebGL；复杂场景的软件渲染可能很慢或失败。不会自动上传或回传。

## 本版变化
- 完整供台后继修复既有卷枝、前桌卷纹外壳和成品表面法线，不新增一套装饰布局。局部外壳、纹理插值及光照响应可能可见，不称外观不变。
- 两盏落地灯采用相反的固定物体朝向，加入真实窄横窗并缩短下格，不跟随相机转动。原灯中心、高度及尺度保持；精确角度属于非唯一建模假设，尖顶与脚位的照片对应仍未解决。
- 原相机、造像、建筑、闭壳铺路、庭院布局和光源保持，不混入后继屋面UV、石灯帽UV或实验塔位。

## 范围和限制
本公开目录仅含运行源码、固定依赖与文件/语法/导入核验器。属于盲做实体修复，没有本版新渲染或照片全景验收。纸窗沿用双面色彩材质及现有普通normal处理，不代表所有背面覆盖已一致。材料提供者保持不等于改变后的阴影、反射或表面亮度相同。原柱边残差、旧开放屋面及宏观取景不确定性仍保留。

不含原始照片、衍生像素标注、历史基线、私有执行报告、测量数据、渲染桥状态、凭据或图片。
