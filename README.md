# KOMOREBI v61

完整可运行寺院场景源码。需要Node.js24.2或更新：执行 `node verify.mjs` 后运行 `node serve.mjs`，按终端地址打开浏览器。参考10条件场景使用 `/?scene=reference10-porch`，其他参考保留默认场景。需要可用WebGL；复杂场景软件渲染可能慢或失败。不会自动上传或回传。

## 本版变化
- 原条件门廊的双面屋面加入同几何的双面normal代理，仅修复原normal/depth背面覆盖；不引入beauty凹凸纹理到几何法线通道。代理在world返回后惰性安装，资源局部归属明确。
- 原石灯帽下增加实际闭合石承座，保持帽、窗框、纸窗、灯点和摆位；与原帽/框有明确装配嵌合，不是整灯Boolean并体。
- 修复原供台软垫角嵌片的局部金属外壳折叠，保留原纹样与放置。这些变化可能改变可见表面、阴影、AO或景深，不称外观相同。
- 相机、原光源增益、庭院布局和其他既有资产保留。构造细节属于建模假设，不是照片唯一恢复。

## 运行与资源范围
normal代理只拥有自己的法线材质和登记，借用原几何/beauty材料。world提供显式disposeRoofNormalOwner接口，使用自定义退休流程时须调用；这不是整个世界或自动pagehide清理器。main正常调用顺序保留，局部异常保护只覆盖原visible与autoClear，不承诺全部renderer状态事务回滚。

本目录仅含运行源码、固定依赖与文件/语法/导入核验器，没有本版新渲染或照片全景验收。原开放屋面、柱轮廓残差和宏观取景不确定性继续保留，不混入失败斜端或实验塔位。

不含原始照片、衍生像素标注、历史基线、私有执行报告、测量数据、渲染桥状态、凭据或图片。
