# KOMOREBI v57

完整可运行的寺院场景源码。需要 Node.js 24.2 或更新：执行 `node verify.mjs` 后运行 `node serve.mjs`，按终端地址打开浏览器。参考10条件场景使用 `/?scene=reference10-porch`，其他参考共用默认场景。需要可用 WebGL；复杂场景的软件渲染可能很慢或失败。不会自动上传或回传。

## 本版变化
- 参考10近柱采用受限轴身轮廓，保留原脚鞋与既有低框接口。柱头、前金轨端托与高低屋面承接共同重建，不移动高梁、灯、屋面或相机。隐藏连接是建模假设，未声称唯一复原或工程认证。
- 修复既有柜面浮雕、挂饰卷枝与背光内卷的外壳，保留原装饰摆位、材质与总体布局。内折面、表面法线及纹理插值可以改变，不称隐藏或外观不变。
- 保留原铺装、路缘支承和岩组，不混入实验塔位、铺装分列或后续候选。

## 范围和限制
本公开目录仅含运行源码、固定依赖与文件/语法/导入核验器。属于盲做实体修复，没有本版新渲染或照片全景验收。画外木构仍可改变阴影路径，不能把几何改进当作画面匹配。局部柱边残差、桥塔/通路/树位的非唯一假设及旧开放屋面层限制均保留。

不含原始照片、衍生像素标注、历史基线、私有执行报告、测量数据、渲染桥状态、凭据或图片。
