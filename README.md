# KOMOREBI v62

完整可运行寺院场景源码。需要Node.js24.2或更新：先运行node verify.mjs，再运行node serve.mjs，用终端地址打开浏览器。参考10条件分支使用/?scene=reference10-porch。需要可用WebGL，复杂软件渲染可能慢或失败。不会自动上传或派发任务。

## 本版变化
- 原抬高荷叶的既有叶柄接到原叶实际姿态下的中心，保留叶片、花、床位与随机布局，不新增根叶。原管端和薄叶并非Boolean闭体，根承土仍未修。
- 两盏原落地灯按原图有限可见窗框关系收拢横向位置和六面窗腔。窗纸、框、横隔和格栅配套调整，不用随相机转向的billboard。原灯高度、深度、尖顶和脚位的纵向差仍未解决，选择不是唯一照片标定。
- 相机、光源增益、庭院布局、屋面及其法线owner代码保持。局部位置与法线改变仍可能影响可见明暗、反射和遮挡，不称图像相同。

## 资源与适用边界
参考10双面屋面的normal代理保留显式惰性所有权，仅借用原几何/beauty材料。自定义退休流程应调用disposeRoofNormalOwner，不是完整场景或自动pagehide清理器。

本目录仅运行源码、固定依赖和文件/语法/导入核验器，没有新渲染、照片全景验收或工程认证。保留宏观取景/塔形、开放屋面和其他未解建模限制。GPU采样器上限等硬件兼容性须以真实渲染结果为准，CPU通过不等于shader编译通过。

不含原始照片、衍生像素注记、私有测量、历史基线、执行日志、渲染桥状态或凭据。
