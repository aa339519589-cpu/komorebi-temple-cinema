# KOMOREBI v58

完整可运行的寺院场景源码。需要 Node.js 24.2 或更新：执行 `node verify.mjs` 后运行 `node serve.mjs`，按终端地址打开浏览器。参考10条件场景使用 `/?scene=reference10-porch`，其他参考共用默认场景。需要可用 WebGL；复杂场景的软件渲染可能很慢或失败。不会自动上传或回传。

## 本版变化
- 保留原石板及路缘顶面，把旧侧面上沿接到实际顶圈、纠正侧面朝向并增加底盖，形成闭合石壳。侧面与底面可能影响可见性、着色和阴影，不称外观不变。
- 配套更新局部让石收头的输入契约，保留它的既有成品形状及承台，不改变原铺装节奏、庭院布局、水膜、岩组或相机。
- 增加独立 pathShellClosure 开关，默认开启；关闭时选择旧石壳/收头契约，支承修复仍开启。路径清理流程同时加强为独立尝试各自有资源并汇总异常，关闭几何开关不回退这项清理行为。
- 前版近柱、供台、灯光与其他资产保持，不混入实验塔位、铺装分列或后继候选。

## 范围和限制
本公开目录仅含运行源码、固定依赖与文件/语法/导入核验器。属于盲做实体修复，没有本版新渲染或照片全景验收。闭合几何不等于结构工程认证，也不代表全部历史场景交界已经修复。局部柱边残差、桥塔/通路/树位的非唯一假设及旧开放屋面层限制均保留。

不含原始照片、衍生像素标注、历史基线、私有执行报告、测量数据、渲染桥状态、凭据或图片。
