# KOMOREBI v54 建筑场景复原

最新完整三维场景源码，包含固定 Three.js 依赖及文件核验工具。模型来自原参考照片的程序化重建，不是生成式图片。原照片不随仓库发布。

## 本地运行

需要 Node.js 24 或更高版本，不需 npm 下载。

```sh
node verify.mjs
node serve.mjs
```

打开 http://127.0.0.1:4317 ，选择参考视角并点击“构建并渲染静帧”。场景有约 2805 万实际三角形，首次构建、环境捕获和阴影渲染较重；浏览器需支持 WebGL2。所有渲染在当前浏览器执行，不自动上传，不控制其他电脑。参考10使用独立条件场景链接。

## 此版范围

- 保留 v53 的参考10真实前景侧廊屋檐、配对旧屋顶开口和近柱承口。
- 两种场景同一开关启用左侧第0–7行路缘的一条连续水下承台，保留原路面和岸石；第8行仍有既有岸石穿插及部分无支承。
- 供台既有花叶根部接合及金属/自然细杆原端面封闭，部分改动可能可见；不新增装饰实例。
- 造像、相机、材质光源和光照预算保持既定来源。
