# KOMOREBI v56

完整可运行的寺院场景源码。需要 Node.js 24.2 或更新：执行 `node verify.mjs` 后运行 `node serve.mjs`，按终端地址打开浏览器。参考10条件场景使用 `/?scene=reference10-porch`，其他参考共用默认场景。需要可用 WebGL；复杂场景的软件渲染可能很慢或失败。不会自动上传或回传。

## 本版变化
- 参考10的侧廊补齐边椽下承框架及配套半搭接，不移动屋面、柱脚、灯或相机。隐蔽连接是建模假设，不是历史或工程认证。
- 修复已有自然花瓣内层的自穿插，保留外形摆位和已有花朵数量。内卷面与法线会改变，不宣称完全不可见。
- 保留此前可回退路缘让石、织纹贴合及表面UV修复。场景装配、光源和相机代码没有因此调整。

## 范围和限制
此公开目录仅包含运行源码、固定依赖及文件/语法/导入核验器。没有新渲染或照片像素验收。画外木构仍可改变阴影路径，不能把几何改进当作已确认的画面匹配。桥塔、通路、树位及隐藏构造仍有非唯一假设，玻璃与局部生命周期也保留既定近似。

不含原始照片、衍生像素标注、历史基线、私有执行报告、测量数据、渲染桥状态、凭据或图片。
