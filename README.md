# KOMOREBI v55

完整可运行的寺院场景源码。需要 Node.js 24.2 或更新：`node verify.mjs` 后运行 `node serve.mjs`，按终端地址打开浏览器。参考10条件场景使用 `/?scene=reference10-porch`，其他参考共用默认场景。需要可用 WebGL；约2800万三角的完整场景在软件渲染上可能很慢或失败。不会自动上传或回传。

## 本版变化
- 修复已有侧廊实体的退化表面UV，保留位置、法线、拓扑与材质。真实纹理/凹凸输入有意变化。
- 既有跪垫织纹贴合真实分片软垫表面，不增加纹样；深度、法线和细分变化。
- 对一块与原岸石相交的路缘作可回退凹口，并加实际下承体。岸石、苔藓和其他铺装不移动；该块可见面积明显缩小，是非唯一构造假设，不是隐藏修补。

shared 和 reference10 均默认启用同一 processionalSupportRepair gate。关闭时也关闭先前两个承台及六部件岩组平移，不是只关闭新凹口。光照、相机、造像及其余31旧模块保持既定来源。
