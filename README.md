# KOMOREBI v66

完整可运行寺院场景源码。需要Node.js24.2+：node verify.mjs，然后node serve.mjs。参考10条件分支使用/?scene=reference10-porch。需要WebGL2。不会自动上传或派发任务。

## 本版实体变化
两株既有岛松改为曲干和平展分层树冠，保留原根位、yaw、名义树高和各五块根饰石。每株281木体部件、5700针叶卡；其他37个旧JS和全部vendor与v65保持。只新增完整松树模块和四处world补线，没有新灯光、材质、相机或曝光变化。

这是有限形体候选，不宣称照片匹配，也没有在这轮修正颜色。可见轮廓、遮挡、世界法线和纹理采样会变化。唯一实际shared CPU观察通过，真实纸窗/玻璃与供台保持；未做GPU验收。

有限邻域木体表面检查未发现建筑、其他石/灯或其他木体交叉，但原三块根饰石与新根干的交叉明确保留；未证明叶片净空、闭体包含或全场无碰撞。原岛面为开放苔藓皮层，不作工程承载保证。第三株原松穿殿基约44.4毫米仍未修复。buildWorld选项prunedPineForms:false可选原树体，不等于完整模块回滚。

## 延续的兼容性与诊断
六个塔窗仍各自产生原阴影并逐层复制到比较深度数组。原12灯、PCF、太阳及点灯阴影不改。源码预算19→14仍待真实GPU编译/帧缓冲/深度复制验证，不会静默关灯、关闭阴影或降低强度。?window-shadow-array=0仅供新renderer旧路对照，仍可能超出设备纹理单元上限。

renderer创建后立即注册持久诊断，覆盖初始build/capture、普通帧和曝光帧。window.templeDiagnostics.snapshot()在启动失败时也可读取；运行API为temple.getRenderDiagnostics()。原debug报告与异常保留。compile/link/context或copy错误必须使任务失败，有效PNG不能覆盖故障。
