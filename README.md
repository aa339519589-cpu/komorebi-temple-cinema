# KOMOREBI v63

完整可运行寺院场景源码。需要Node.js24.2或更新：先运行node verify.mjs，再运行node serve.mjs，用终端地址打开浏览器。参考10条件分支使用/?scene=reference10-porch。需要可用WebGL。不会自动上传或派发任务。

## 本版变化
两块最长中层金雕板由统一双龙围珠改为各一条朝内的原有长龙，尾身朝外。其余图案、背板/边框、灯位、相机和庭院不动。使用原有铸饰组件的选型和真实实例变换，没有增加细小纹样或随相机转动的平面。

原图支持单龙朝内构图，但不唯一确定精细角爪鳞片、深度或横向比例；这些仍是有限复原假设。选型和变换会改变可见反射与阴影，不能称图像不变。减少发射三角不等于减少存储，因为原双龙原型仍在其他板使用。

## 适用边界
本目录只有运行源码、固定依赖和文件/语法/导入核验器，不含新渲染或照片验收。既有双面屋面normal代理保持惰性借用所有权，自定义退休流程仍需调用disposeRoofNormalOwner。

已知部分材质存在GPU采样器预算超限风险，本轮未修复；CPU通过不代表shader编译或实际渲染成功。宏观取景/塔形、开放屋面及其他未解建模限制仍保留。

不含原始照片、衍生像素注记、私有测量、历史基线、执行日志、渲染桥状态或凭据。
