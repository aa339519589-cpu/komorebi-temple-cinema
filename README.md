# KOMOREBI v64

完整可运行寺院场景源码。需要Node.js24.2+：node verify.mjs，然后node serve.mjs。参考10条件分支使用/?scene=reference10-porch。需要WebGL2。不会自动上传或派发任务。

## 本版变化
六个塔窗仍各自产生原始投影阴影，光源、强度、相机和材质均保留。原阴影完成后，把六张深度图逐层复制到一个比较深度数组，消费端共用采样器，降低常规PBR程序的纹理单元需求。原五点PCF公式及其他太阳/点灯阴影路径保持。

这是源码及CPU检查通过的兼容方案，尚未经过真实GPU编译、帧缓冲、深度复制或图像验证。不会静默关闭灯/阴影；数组失败明确报错，不偷偷退回超限路径。额外深度存储和逐层复制有成本，性能待测。?window-shadow-array=0仅供新renderer的旧路对照，仍可能超过设备上限。

## 可靠失败状态
renderer创建后立即注册持久技术诊断，覆盖初始build/capture、普通帧和曝光帧。window.templeDiagnostics.snapshot()在启动失败时也可读取；运行API为temple.getRenderDiagnostics()。原debug报告保留，异常不被吞掉。

编译/链接/上下文故障一旦出现，本次任务永久标失败；有效PNG不能改写该状态。预览入口在帧后及导出前后核诊断，只提供无已记录shader错误的结果，不据此宣称照片匹配或完整图像正确。原模型布局、宏观取景、开放屋面和其他未解决限制仍保留。

本目录仅含运行源码、固定依赖和核验器，不含原始照片、衍生像素注记、私有测量/执行日志、旧基线、源指纹元数据、渲染桥状态或凭据。
