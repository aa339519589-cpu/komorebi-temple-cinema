# KOMOREBI v65

完整可运行寺院场景源码。需要Node.js24.2+：node verify.mjs，然后node serve.mjs。参考10条件分支使用/?scene=reference10-porch。需要WebGL2。不会自动上传或派发任务。

## 本版实体变化
供台下层正面五栏采用外侧较宽、邻内侧较窄的构图，固定总宽、中央栏的数学宽度、四个间隙及柜面边界。仅调整既有四栏及两分隔条的实例变换，不新增雕刻、灯光、相机或材质。4:3属于有限建模选择，不是原图唯一测定比例。可见表面、世界法线、反射和阴影会变化。

完整源码及有限实际CPU提交检查已通过；未做GPU或照片验收。其他几何、纸窗/玻璃、灯位、所有源值和原阴影语义保持。仅供台源码相对v64改变。

## 延续的兼容性与诊断
六个塔窗仍各自产生原始阴影，随后逐层复制到一个比较深度数组，消费端共享采样器。原PCF、太阳及点灯阴影不改。这是尚待真实GPU编译/帧缓冲/深度复制验证的兼容方案，不会静默关灯、关闭阴影或降低强度。?window-shadow-array=0仅供新renderer的旧路对照，仍可能超出设备纹理单元上限。

renderer创建后立即注册持久诊断，覆盖初始build/capture、普通帧和曝光帧。window.templeDiagnostics.snapshot()在启动失败时也可读取；运行API为temple.getRenderDiagnostics()。原debug报告与异常保留。compile/link/context或copy错误必须使本次任务失败，有效PNG不能改写故障。未据此宣称图像正确或照片匹配。

本目录仅含运行源码、固定依赖和核验器，不含原始照片、衍生像素注记、私有测量/执行日志、旧基线、源指纹元数据、渲染桥状态或凭据。
