# Publication boundary

The 35 runtime JavaScript modules and 22 vendored dependency/license files are byte-identical to the frozen private v55 package. Only runnable entry points, a lightweight verifier and publication documentation accompany them. No original-photo evidence JSON, per-pixel measurements, historical baseline trees, private terminal receipts, bridge state, credentials or returned images are included or re-encoded.

The private full package is not a public upload manifest. This directory alone is the bounded source-only publication candidate. No repository upload or ref update has been performed by this preparation.
