# Scene05 — 薄铜端套与朱木受光候选 mesh72

以 struct64-native 为基底，保留原低相机、五层塔的尺度、位置、屋面和木构布局。本轮仅修改主要金属端护件、朱木表面和相关日照/庭院反射近似，曝光仍为 .95，太阳强度仍为 4.4。瓦材的深蓝灰颜色与粗糙度保持原值。

`src/rafter-end-copper.js` 提供四边回折的闭合薄铜套，带八片连续弧面花瓣、四段有限宽卷草、边框、铆钉与较低的暗铜凹槽底。各部分由闭合实体组成。名义面板厚为构件最小截面的 .022，回折深度为 .10；在 20cm 端头上分别约为 4.4mm 与 20mm。细小护件用同轮廓的较低细分版本。悬垂角木的端套现在跟随真实切面法线，不再只按水平朝向放一张竖直花牌。极小、无细节的旧端件仍保留简化几何。

原来朱木预设颜色随后被深色 CC0 桌面扫描的高增益颜色覆盖。`src/scanned-timber.js` 现用不透明颜料控制朱红/暖木反照率，并将同一 Poly Haven CC0 扫描的亮度归一化为 .68–1 的木纹调制，保留其法线、粗糙度和构件尺寸 UV。没有使用参考场景照片做颜色纹理或深度。朱红颜料为 `#b65325`，暖木为 `#9d592f`，真实扫描源文件没有改变。

太阳沿原方位降低约 7°，光色改为暖金；强度未加大。庭院反射方向光由 .20 调为 .28 并启用实际阴影，以保留檐下层次。解析天空和独立立方体环境继续使用，太阳方向同步。庭院光仍是明确标记的首次反射近似，不是测量或完整 GI。

两轮共享 mutex 的原生 1254px 全图及同机位 `(745,690,320,1254)` 子视锥见 `qa/ten-reference/05/iteration-mesh71/`、`iteration-mesh72/`。基底/首轮源快照、原图/struct64/候选对照和新铜件闭合性回执见 `qa/ten-reference/05/mesh71-review/`、`mesh72-review/`。没有运行测试套件或电影。

此候选尚未验收。花瓣和卷草仍较概括，未逐笔重建参考铸件；朱木涂层比原图更均匀，磨损、反射和屋檐明暗仍需复核。旧窗饰、极小端件、陶瓷角兽以及更广的建筑比例和树叶差距保留。闭合性与渲染有效不能证明照片级匹配。
