# Scene08 — 门框庭院实体细节候选 mesh70

当前 `watercourt131` 为未合并的桥—梯—岸线路候选：已完成本轮原机位 B1 与修正后侧视 B2 两张真实渲染。两帧源不同，最终 B2 原机位尚未复验；岸坡/石脚块面、接合与整体照片比例仍未验收。[实际图、四个路线端点与版本记录](../../qa/ten-reference/08/watercourt131/README.md)。

`terrain127` 现有未合并的整体地形候选：闭合阶地土石体、真实分级水道、植株/岩石落地以及旧廊屋抬楼面并缩短墙柱。两次实渲已结束，最终 CPU 审核明确检出六处廊屋楼面与其他建筑旧基础相交，水道和园林外观也仍不匹配；此候选已拒绝，不应合并或视为连贯场地。[实体地形、失败剖面与前后证据](../../qa/ten-reference/08/terrain127/README.md)。

当前另有 `layout122` 整体布局候选：门廊、近栏杆、殿廊层高、塔层距与桥阶连接均已重新组织，旧文下述“原位置保持不变”仅指历史 mesh70。此候选未验收，场地灰色台基仍明显侵占参考图的园林与水道。实际三轮整帧、十五点轮廓量测、失败源快照与结构连接检查见 [layout122 记录](../../qa/ten-reference/08/layout122/README.md)。相机、照明、雕刻牌资产与已选中性岩石扫描保留。

`foundation126` 仅修正已射线定位的桥头与回廊基础：双侧落地石墩托石平台、六个独立柱脚基础，并保留原楼面承重关系。一次实渲整帧与原生局部已完成，几何通道存在但原相机仍被石墩遮挡，照片的水道开口尚未复原；该候选同样未验收。[结构剖面、地形接触与实际证据](../../qa/ten-reference/08/foundation126/README.md)。

本轮以已选 struct50 为基底，只处理前景朱柱五金与左侧大殿/回廊木构。门框、建筑、塔、园林的原位置及原低相机保持不变。

`src/gate-hardware.js` 生成有实体板厚的五金背板、嵌框、铸花、叶纹、铆钉和四面柱脚包角。背板厚 16mm，倒角 4.5mm；内场、花瓣与铆钉均有各自体积。原正面五金保留，并补入朝庭院的内侧叶片牌；内侧牌的高度与尺寸根据原图可见段作推断，尚未作位置/花形验收。金材粗糙度 .43、金属度 .86，没有使用原照片的颜色或图案纹理。

`src/gallery-joinery.js` 从 scene01 的闭合实心弧形套件本地派生，用 30 件弧形挑栱、半搭接横栱、曲面承托斗和薄暗金端鞋替换左廊的密集金色方块。椽材和挑檐侧梁沿原屋面连续扫掠、封闭端面；左廊盖瓦改为有壁厚、封闭切口与头搭接的半筒瓦。原有 CC0 木纹继续按构件尺寸映射。塔和其他廊屋的斗栱没有一同替换。

三次原生 1254px 实渲均通过共享 GPU mutex：mesh68 检查左廊原位子视锥，mesh69 检查新增内侧铸花牌，mesh70 收薄边框与浮雕并复查同一五金子视锥。实际图及源身份在 `qa/ten-reference/08/iteration-mesh68/` 至 `iteration-mesh70/`。首两轮源快照、拓扑回执和原图/struct50/mesh70 对照在 `qa/ten-reference/08/mesh70-review/` 及相邻源快照目录。

新增实体在 1e-5 位置焊接检查下边界边与非流形边均为零；这只说明闭合性，不代表形状与照片一致。本候选仍有明显差距：五金花纹是同题材的程序雕刻，尚未逐笔重建原铸件；左廊某些承托仍偏密、阴部偏暗；瓦端帽及既有主体结构还有重复感。原场景的植物、石灯、屋顶比例和光照差距保留。不得将此候选标为照片级完成。
