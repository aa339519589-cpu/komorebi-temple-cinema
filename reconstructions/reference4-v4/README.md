# Reference 4 exterior reconstruction

A complete independently runnable Three.js exterior scene based on original photograph 4. All scenery is geometry and procedural material, not a background photograph.

Serve this directory over HTTP and open index.html. The root project and other reconstruction versions remain separate.

This is newly rebuilt source following the execution-environment reset, not a byte-identical restoration of lost exterior v3. It contains the complete connected-roof architecture, garden, real sanctuary, cloud atmosphere, water reflections and distant forest. It still requires actual image comparison and is not declared a finished photographic match.
