# Scene07 layout118 — unaccepted reconstruction work

The prior scene used narrow rails with an arbitrary repeated line of gold caps, a bridge spanning almost the whole garden, and a foreground roof with the wrong orientation. This work replaces the near balustrade as a broad joined timber assembly, reconstructs the bridge plus descending flight, and rebuilds the main stair/landing route from shared elevations. Stone treads are four separately jointed granite slabs per row with12mm rounded edges, metric CC0 material maps and coursed backing. The10 main risers are160mm,320mm tread;3 connecting risers are166.7mm.

Reference coordinates are manually observed silhouettes. Heights/depths are inferred and changed when independent placement produced overlapping components. The observation file is not a calibrated survey and its exact point reprojection is not a fidelity score.

Rejected iterations:
- sky116: measured CC0 sky split rendered a washed-out sky and cold subject, not closer to the reference. Reverted from runtime. Source retained in lookdev/scene07-sky116-rejected.
- layout118: first rail/bridge layout used that rejected light.
- layout118b: main stair/bridge/landing connection was incoherent; independent fitted slabs crossed the old stair volume. Rejected. Source retained beside this README.
- route118c: revised connected geometry with original lighting; still has wrong inherited foreground roof and very synthetic appearance. Island smooth-core candidate was replaced by real scanned rock cores afterwards.
- route118-side: independent side view of the actual route after core replacement. This is targeted geometry inspection, not proof that all scene collisions or motion flicker are absent.

All10 photographic reconstructions remain unaccepted. No final movie is claimed here. Remaining major defects include main architecture/landscape proportion, coarse light/material response, copied generic elements, foliage, water appearance and overall reference mismatch.
