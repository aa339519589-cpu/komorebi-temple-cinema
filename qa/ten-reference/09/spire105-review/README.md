## 实际模型与照明

新增 src/pagoda-finial09.js，共28个独立闭合实体、30,016三角形：9道有内孔、斜腹、圆钝轮缘和背面的铸轮；连续轴、逐轮轴套、根部车旋座、两道上端轴箍、4根简化支杆、2个小珠形轴节。各零件为实网格，内孔承接连续轴。无照片贴片、视图纹理、新模型下载或场景图像资产。

金属材质只作用于相轮，metalness=1、roughness=.36、emissiveIntensity=0。线性RGB[1,.766,.336]由Color.setRGB(..., LinearSRGBColorSpace)写入，依据[Epic官方PBR金属表](https://dev.epicgames.com/documentation/en-us/unreal-engine/physically-based-materials-in-unreal-engine)。这是金属表面解释；并非测得这座塔的镀金成分或粗糙度。

唯一新增灯是**推定**的屋顶小聚光灯，具有阴影、有限向上锥角及平方距离衰减。最终世界位置[-11.399571,23.4142,-14.845044]，目标[-13.6,27.0622,-17]，intensity=90（渲染器工作值，非现场照度测量），distance=8.8，半锥角=.41rad（约23.5°），penumbra=.55，decay=2，色值0xffd29a。灯源在原有顶层屋面上方，朝相轮上射；不增加全局填光。

第一轮的近轴灯位使轮间互遮、轮缘高光偏白，轮腹也过平。第二轮只将轮腹/轴腹加圆钝，让实体承接更饱满；同一盏推定灯沿顶层屋面向外移，以斜向实际光路照到轮下表面，并将强度180减为90。材质色、粗糙度、环境及其余参数未变。

## 得失与限制

实际观察：黑色空环已变成有厚度的暖金铸轮，第二轮比第一轮减少了白色高光。未见明显塔身泛亮。CPU描述统计中，暖色轮缘像素RGB中位数为原图[110,70,44]、105[195,144,77.5]、105b[144,103,52]；选区并不等面积/等表面，对比只用于说明偏亮问题，不能作为匹配率。

仍存在明显差距：轮盘/轴节过于规整，上端真实小构件尚无可靠分辨，根座被既有屋面前沿部分遮挡，轮下深处仍偏暗。保留原塔身和屋面造成相轮顶点仍在约(329,37.6)，比原图低约18px，未通过拉伸整塔、移动屋面或改相机掩盖。参考的小金属细节和真实夜间光路仍不足以从这一照片唯一确定。此候选不等于精确复原或完成。
