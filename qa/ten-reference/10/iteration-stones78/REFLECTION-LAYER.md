# Existing planar reflection / stone relationship

Current source locations refer to this candidate's `reconstructions/scene-10/src/main.js`.

- Line 118 creates a single `Reflector(new PlaneGeometry(8.9,22))`, horizontal at `(-.1,.066,8.5)`. It spans x [-4.55,4.35] and z [-2.5,19.5]. Its reflected texture is 768 square, transparent, with depthWrite=false. All twelve stone cap ranges lie below it: approximately y=.032–.053 m. It therefore presents a flat reflective surface about 13–34 mm above actual stone highs/lows.
- Lines 119–133 modify the planar UV image using centimetre ripple noise and a generated floorWetMap. Alpha is a mix of wetness, edge fade and grazing angle; non-paving gaps retain alpha .17. No part of this plane reads the individual stone mesh height or its basin/pit normals. The physical drain is excluded analytically, but individual stone low/high spots are not.
- Lines 89–90 already assign the actual granite albedo, normal and roughness maps to the existing `MeshPhysicalMaterial` m.wet, with clearcoat .55 and a separate grain normal. The twelve selected stones already render with this same material. `surface-detail.js` lines 34–46 preserve geometry normals and add water-grain normal perturbation / spatial clearcoat / roughness. These shaders can reflect from the real carved mesh without adding triangles.
- Line 201 supplies the general independent grey environment and scene.environmentIntensity .58. The m.wet envMapIntensity is configured as 1.5, but m.wet has no explicit envMap; the renderer uses the scene's environment intensity for that case. This general environment contains grey sky/ground forms, not actual hall/lantern/garden objects.
- Lines 220–221 already capture an actual-scene 256-square cube environment, once, at (0,2.3,7), with the planar mirror temporarily hidden. It is assigned only to m.gold, m.oldgold and m.nearLacquer, not m.wet. A separate near-stone material clone can retain the current PBR / floorWetMap shader while receiving that actual-scene probe, or a probe at a closer valid capture point. Explicit envMap assignment then uses its material envMapIntensity. Reinstall `installSurfaceDetail(clone,'wet')` and bind clone.userData.floorWetMap; Three's ordinary clone does not preserve that custom compilation callback automatically.

A focused next correction can exclude only these twelve actual footprints from the high flat Reflector and use their already existing real-surface PBR reflection. The mask alpha channel is not currently consumed by the wet shader and could identify selected footprints separately; the current per-polygon edgeFadeMetres also distinguishes this set. Actual-scene cube reflection has parallax limits, so it must be visually checked at the fixed near opening pose. This is an unimplemented follow-up option, not a verified render result. There is no reason to increase stone triangle count for this optical relationship.
