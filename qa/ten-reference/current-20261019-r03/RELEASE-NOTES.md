# 十景实体三维渲染 · r03 制作进度

本版仍未达到参考图的细节和摄影质量，不作为达标成品。

影片来源固定为 `db08d1e`，1440×1440、30fps。十景均由真实三维实体、材质、灯光与相机渲染。参考照片不作为全帧背景、深度点场或视频替代画面。

相对r02，本版修正04石板上方格状、字形般的侵蚀轮廓，改用稀疏圆钝浅坑，并把真实石道、双侧路缘和接缝地基延续到机位后方。原图可见的31块石板与隐藏的推断延续明确区分；后者不是测量恢复的照片细节。另九景源码相同的实际镜头按哈希复用。

70秒版保留十个7秒源镜头；60秒版通过九次叠化重叠10秒，镜头运动未加速。附件保留十条源镜头、首/中/末实际画面、原图与渲染对照、来源与媒体记录。

公开代码在此后还会继续修改；本影片的精确冻结源和逐景身份见 `film-build.json`，不要将后续代码变化误认为已经进入本影片。

配乐：PeriTune / Sei Mutsuki《Oboro》（2019），CC BY4.0。原曲25秒起的片段经过响度调整和淡入淡出。
