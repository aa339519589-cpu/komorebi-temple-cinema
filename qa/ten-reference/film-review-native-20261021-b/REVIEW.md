# Ten-scene production checkpoint B

Photographic acceptance remains false. All ten clips are actual native Three.js framebuffer renders at 960 square, 24 fps, seven seconds and 168 frames each. This checkpoint updates the stone approach, low pagoda-corner framing, central sculpture, night courtyard and rain courtyard. Source 03/08 and later sculptural/garden work continue separately and are not represented as finished here.

Every source-file set and SHA-256 was verified against immutable public commit c6841adf380453067c27dc09882d1f20c0d36787 before reusing the corresponding source clip. The next model revision does not silently alter this film. The exact clip identities and combined video hashes are in film-build.json.

The 60-second edit contains 1,440 frames with nine source overlaps. The 70-second cut retains every seven-second clip. Music: PeriTune / Sei Mutsuki, Oboro, CC BY 4.0, https://peritune.com/blog/2019/04/08/oboro/ ; selected segment, normalization and fades.

frames.json selects actual canonical native stills with the same source identities as the clips, including an explicitly byte-identical alias of the scene04 canonical shadow-profile frame. The comparison board shows reference left/native right for all ten scenes.

The models still differ substantially from the reference in visible architecture, statuary, vegetation, microgeometry and photographic light/material response. This is a review checkpoint, not a finished fidelity claim.
