# Reference 05 independent reconstruction

Original inspected at full resolution: `references/hd/5-照片-6.jpg`.

Entry: `reconstructions/scene-05/index.html?render&defer&w=768&h=768`.

The scene is a complete five-storey, four-sided timber tower. The camera is at 1.02 metres, close to its corner, and deliberately crops the upper tower. Roofs contain curved interlocking tile grids, ceramic round ends, two real rafter layers, and large continuous hip timbers. Corner brackets use real notched receiving blocks with open air between the arms. Gold fittings are border straps and flower reliefs rather than yellow replacement cubes. Lantern paper, six-sided bronze frames, crowns, suspension rods and lobed maple leaves are separate 3D geometry.

All imagery is generated by the code: neutral grain/bump DataTextures, analytic cloud sky, procedural environment radiance, and geometry. No source photograph texture, downloaded asset, model, HDR or generated AI image is used.

CPU validation: `node qa/ten-reference/05/cpu-check.mjs`. This builds the real scene using the vendored Three modules and a minimal canvas placeholder; no browser or GPU process is started. First build: approximately 1.2 seconds, 2.58 million architectural triangles and 17,035 architectural components, merged by material. This validates construction, not visual agreement.

Root owns GPU serialization. Pending: actual 768-square default render, source/render side-by-side inspection, and camera/material correction from those real pixels. No visual acceptance asserted.

API: `window.temple = {ready,renderer,scene,camera,renderReference(5),renderView(position,target,time,fov),renderShot(localTime),info(),dispose()}`. The `defer` parameter performs no automatic rendering; there is no RAF loop. Reference renders directly to the default framebuffer with `preserveDrawingBuffer:true`.
