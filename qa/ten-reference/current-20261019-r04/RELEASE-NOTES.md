# 十景实体三维渲染 · r04 当前制作进度

十景仍未达到参考图的细节、色彩和摄影质量，本版不是达标成品。

来源固定为 `0f9dec9`，1440×1440、30fps。十个场景由实际三维实体、独立材质、灯光与相机输出。

相对r03，03重建主殿下缘与塔身真实窗洞，细化曲面荷叶材质，校正闭合花苞的位置、尺度与茎部连接，并使用带明确光圈参数的拉远对焦；04按可见塔尖／檐角调整塔体并打开原来被墙盖住的窗格；06按可见板缝重建21块前景厚木板，让反射进入板面清漆；09两盏近景灯更换为真实镂空铜框，并修正纸面规律条纹。

本版重新渲染03、04、06、09，另六景严格复用源码哈希相同的已有实际镜头。可见观测与隐藏结构／材料推定均有独立记录，不声称从单张照片恢复了不可见细节。

70秒版保留十个7秒源镜头；60秒版通过九次叠化重叠10秒，镜头未加速。附件保留十条源镜头、首／中／末实际画面、原图与渲染对照及逐景来源。
