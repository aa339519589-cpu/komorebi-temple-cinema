# Rendered files

Large movie files, lossless frame intermediates and the earlier source ZIP are preserved in the public repository's [checkpoint release](https://github.com/aa339519589-cpu/komorebi-temple-cinema/releases/tag/checkpoint-2026-10-16).

Extract all checkpoint ZIP parts into the project directory to restore their original paths. The manifest under [archives/](../archives/) records every included file, size, SHA-256 digest and ZIP part.

`komorebi-60s.*` and `komorebi-70s.*` are the **rejected V1**, not final delivery. The V2 clips are camera tests. `draft-v3/70s/shot-*.mkv` contains the partially rendered revision stopped at the user's request before publication; it is not a complete film.
