# Third-party materials

The project code is MIT licensed. The following materials retain their own terms.

- **Three.js:** MIT; bundled license at [vendor/LICENSE](vendor/LICENSE). The bundled code includes marching cubes, area-light BRDF lookup data and postprocessing utilities. These are rendering-library components, not photographic scene assets.
- **Current soundtrack — “Oboro” by PeriTune / Sei Mutsuki:** [original work and license](https://peritune.com/blog/2019/04/08/oboro/), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The artist's [2026 update](https://peritune.com/blog/2026/03/01/terms-update/) preserves the CC license for older tracks. The 2019 track is used in edited excerpts with normalization and fades. See [CREDITS.txt](CREDITS.txt).
- **Historical V1 soundtrack — “Hiraeth” by Scott Buckley:** [original work](https://www.scottbuckley.com.au/library/hiraeth/), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). It remains in the archive because it was part of the rejected first draft.
- **Reference photographs:** supplied by the user for visual reconstruction. They are excluded from the project's MIT grant. See [references/README.md](references/README.md). The scene renderer does not load these photographs.
- **Lacquered Cherry Wood PBR maps:** [Poly Haven asset](https://polyhaven.com/a/lacquered_cherry_wood), scanned by Jenelle van Heerden and processed by Rico Cilliers; [CC0-1.0](https://polyhaven.com/license). Original downloadable map bytes and their MD5/SHA256 checksums are retained in `assets/polyhaven/lacquered-cherry-wood/provenance.json`. The timber tint and member UV mapping are modified in scene code.
- **Image-assisted architectural relief:** the built-in image generation tool produced a non-metric grayscale sculptural guide using the user's architectural reference. Provenance, full prompt, editable Blender source, source builder and actual mesh inspection are retained in `lookdev/gilded-kiku-v01` and `assets/temple-joinery-v01`. This is a generated guide used for actual relief geometry, not a replacement film frame.
- **Museum sculpture study:** [Chinese Amoghasiddhi Buddha, 1403–1424 CE](https://collections.artsmia.org/art/31240/amoghasiddhi-buddha-china), published by the [Minneapolis Institute of Art](https://sketchfab.com/3d-models/33699be99fd64375bf0371c0e0c12f70) under CC0-1.0. The unchanged source GLB comes from the public Objaverse dataset mirror; author and license are verified against the museum's published model metadata. It is a separate anatomical study, not yet selected for a reference scene. Source bytes, hashes and processing scripts are included in `assets/mia-amoghasiddhi-study` and `lookdev/mia-amoghasiddhi-study`.

Earlier reconstruction revisions used code-generated visual geometry and maps. On 2026-10-18 the user explicitly authorized image generation, Blender and other tools to improve the modeling. The current scene05 candidate adds the documented Blender-built solid joinery kit, image-assisted relief geometry and CC0 scanned timber maps. The rest of the scene source remains individually documented. Reference photographs are never used as scene backgrounds or as substitutes for actual 3D geometry.


## Additional parallel reconstruction materials, 2026-10-18

- Scene04 paving uses Amal Kumar’s CC0 [Monastery Stone Floor](https://polyhaven.com/a/monastery_stone_floor), physical width1.8m. Downloaded originals, interior crops and SHA256 provenance are retained inside `reconstructions/scene-04/assets/monastery-stone-floor/`. A single stone interior supplies the face grain; actual modeled paving joints remain geometry.
- Scenes01,02,03,07,08 now also use the already credited Poly Haven lacquered cherry scan with member-aligned UVs and separately tuned coating/colour. Source maps remain CC0; local provenance accompanies the derivatives.
- Physical lighting studies use Greg Zaal and Jarod Guest’s CC0 [Qwantani Sunset Pure Sky](https://polyhaven.com/a/qwantani_sunset_puresky). The original 2K EXR and its SHA256 are retained in `assets/polyhaven/qwantani-sunset-puresky/`. It supplies measured world radiance and reflections; it contains no temple or reference-image geometry.
- Scene01 garden stones use Kless Gyzen’s CC0 [Rock Moss Set 01](https://polyhaven.com/a/rock_moss_set_01). The six separate scanned meshes and original 4K PBR maps are retained with provider MD5 and local SHA256 checksums in `assets/polyhaven/rock-moss-set-01/`. Stones are individually placed and shaded in 3D; squat scan proportions are preserved, and the coating tint is modified.
- An additional physical sky study uses Greg Zaal and Jarod Guest’s CC0 [Kloppenheim 06 Pure Sky](https://polyhaven.com/a/kloppenheim_06_puresky). The unchanged 2K EXR and provenance are in `assets/polyhaven/kloppenheim-06-puresky/`.
- The unselected anatomical study in `lookdev/makehuman-buddha-study/source/` uses MakeHuman Community’s base mesh and Asian male target. MakeHuman’s [official license](https://static.makehumancommunity.org/about/license.html) and the complete included `LICENSE.md` identify the base mesh and targets as CC0 graphic assets. The software’s separate code license does not apply to these graphic files.
- `lookdev/buddha-face-study/` preserves an **unselected** image-assisted skin scaffold study. The canonical468-vertex topology comes from Google MediaPipe0.10.21 under Apache2.0; its complete license is included in that directory. Inferred depth is not a metric scan and the generated clay image is not a scene albedo or a replacement frame. Exact generation prompt, original reference crop, intermediate geometry and actual Blender views are preserved.
