This directory is an unaccepted sculpture-guide study. The guide is an AI-created bitmap and is not a 3D rendering or part of the film. The official MIT TRELLIS.2 demo accepted preprocessing but rejected generation because anonymous ZeroGPU quota was zero. No TRELLIS.2 mesh was produced, and its generated appearance has not been used in a scene. The separate local TripoSG experiment uses the original MIT code revision before the later FlashVDM acceleration. Its output must be an explicit untextured mesh, visually checked under the existing scene camera and gold material before any adoption.
